# The author's other submission

NEAR HACKATHON rule Q-015 allows one person to submit two projects if they are independent and each README names the other.

The same author has a second submission to this hackathon:

- Project: **Leash**, a NEAR wallet contract that enforces a spending policy for each AI agent key (tracks: AI Security & Defense, Business, Agents).
- Repository: https://github.com/enerzy17/leash (the link goes live when that submission is filed)

The two projects are independent. Leash is a Rust contract with a JavaScript client. Epoch Ledger is standard-library Python that reads public chain data. They are separate repositories in different tracks and share no code and no data.
